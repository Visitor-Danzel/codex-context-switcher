# Codex Context Switcher

中文 | [English](README.en.md)

## 重要纠正：清单方式已暂停

版本 **2.2.5 / 13** 是安全收回版，**不是满足“只改上下文、原生模型列表不变”的逐模型最大上下文成品**。

旧版本通过 `model_catalog_json` 提供逐模型上下文设置，但这个配置也会接管 Codex 原生模型列表的数据来源，阻止正常在线模型发现。清单过期时可能缺少新增模型。此前把“没有修改客户端程序”当成“原生列表不受影响”的保证是不准确的；2.2.4 更新清单也没有消除这个根本副作用。撤回此前的完成/推荐结论。

**当前真实配置下，保存和重新安装清单的撤销都已禁用；不再建议使用旧版本启用或升级清单。** 保留只读检查、明确确认的“恢复默认”和不改配置的中断记录检查。原始功能代码仅在严格一次性测试模式保留，用于历史回归，不能作为真实可用承诺。

## 先恢复原生模型发现

1. 正常构建并打开本工具：`sh scripts/build-context-repair-candidate.sh`，再运行 `open "build/legacy-context-repair-candidate/Codex Context Switcher.app"`。
2. 完全退出 Codex 和官方 CLI，关闭配置编辑器。
3. 在本工具点击“恢复默认”，阅读撤回说明并明确确认。该操作只移除已识别的、本工具写入的 `model_catalog_json` 覆盖；**同时撤回本工具提供的最大上下文设置**。其他配置保持原样，先备份并验证外部改动。
4. 重开 Codex，检查原生模型列表。Terra 的官方入口在 Advanced／高级，实际可用性仍由账户和工作区控制。

不要继续点击旧版的“保存”更新名单，不要删除原生聊天或数据库，也不要修改、重签 Codex。退出本工具或安装新版都不会自动撤回真实配置，仍需上述明确操作。未知/损坏清单、配置冲突或中断保存会先停止，不能强行绕过检查。

## 尚未完成的目标

目标仍是对 GPT-6.1 Sol、GPT-6 Astra、GPT-6 Luna、GPT-6.1 Terra 等各模型独立切换最大上下文，同时原生模型列表及其他行为保持不变。**目前没有经过验证、满足这个完整约束的替代实现。** 不会用共享容量开关冒充逐模型功能，也不会用替换清单冒充只修改上下文。

官方 `model_context_window` 是直接容量设置，但没有在本项目验证出按模型独立持久控制且不接管列表的官方通路。后续必须先证明满足约束，再启用写入。

## 界面、构建与保护

右上角可选中文／English，默认中文；语言切换只改文字，不写配置。图标随源码打包。

<img src="AppIcon.png" width="128" height="128" alt="应用图标">

已测试 macOS arm64 与桌面内置 CLI `0.165.0-alpha.1.2`，本机程序位于 `/Applications/ChatGPT.app`。需要 Xcode Command Line Tools、Python 3.11 或更新版本。脚本不修改原生程序，不读取聊天数据库、认证文件或钥匙串；配置工作进程禁止联网。配置路径、身份、预览确认、外部修改、进程退出与独占编辑保护保留。不会自动覆盖或回滚；保留备份。

构建后运行 `sh scripts/test-maximum-context.sh`。测试仅使用明确列出的隔离资料；通过技术测试不等于满足原生列表不变的产品要求，也不证明真实撤回已经完成。历史证据和当前纠正见 [ACCEPTANCE.md](ACCEPTANCE.md)。公开源码不含真实配置、聊天、生成的原始模型清单、私人验收记录或其他产品模块。
