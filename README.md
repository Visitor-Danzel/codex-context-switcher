# Codex Context Switcher

中文 | [English](README.en.md)

macOS 逐模型最大上下文切换器，版本 2.2.4 / 12。

勾选需要扩展的模型，保存后重新启动 Codex。未勾选的模型保留默认上下文；支持恢复默认、撤销上次保存，退出并重开工具后从实际配置重新读取状态。

## 界面语言

右上角选择“中文”或“English”。默认中文，切换只改变界面、提示和弹窗文字；不触发保存或刷新，不改变模型勾选、未保存选择或按钮可用状态。语言选择仅在本次运行中有效，重新打开工具恢复中文，不写入 Codex 配置。

## 使用

1. 安装 Xcode Command Line Tools、Python 3.11 或更新版本，以及当前支持的 Codex 桌面程序。工具寻找 `/usr/local/bin/python3` 或 `/opt/homebrew/bin/python3`。
2. 在源码目录运行 `sh scripts/build-context-repair-candidate.sh`，再运行 `open "build/legacy-context-repair-candidate/Codex Context Switcher.app"`。
3. 勾选模型，点击保存。退出 Codex 桌面及官方 CLI，关闭配置编辑器，然后在工具确认框确认保存；保存期间不要让其他程序编辑配置。
4. 重新打开 Codex 后使用。需要撤销时，再退出 Codex，并点击工具的“撤销上次保存”。

查看原生聊天容量：按 `⌘,` 打开 Codex 设置，在“常规”中开启“显示上下文窗口使用情况”；回到所选模型聊天，将鼠标停在输入框下方的上下文圆环，查看“共 …k”。没有可用用量时，先让该模型完成一条简短回复。显示是否出现和保存状态不同，不能把切换器里的配置数字当成聊天实际容量。

保存过程中要求 Codex 退出，是为了避免同时编辑配置；保存后重启，是因为 Codex 在启动时加载模型清单。关闭工具不会自动撤回设置，重启工具会重新读取当前配置。

## 客户端更新、模型缺失与旧设置升级

本工具不会修改 Codex 原生程序，但保存的 `model_catalog_json` 会指定原生模型列表的数据来源。本地清单优先于在线模型发现；它是构建时安装版本的快照，不会自动补入之后新增的模型。客户端更新后仍引用旧清单，可能看不到新模型。

2.2.4 / 12 适配内置 CLI `0.165.0-alpha.1.2` 的完整 12 模型清单，包括 GPT-6.1-Terra（默认 500000、最大 872000 tokens）。工具只改变你勾选模型的上下文值，其他字段使用当前完整官方快照。它不会授予模型访问权限。

升级步骤：打开新版工具，确认原有勾选已保留；若显示“模型清单需要更新”，完全退出 Codex 和官方 CLI、关闭配置编辑器，再点“保存”并确认。重开 Codex 后查看模型列表的 Advanced／高级。更新工具本身不自动修改真实配置；当前聊天不会即时扩容。

只有自有路径、文件内容校验和历史模型字段都匹配已审核记录的旧清单，才会显示可升级。未知清单、非上下文字段篡改和无效上下文值仍会停止操作。旧文件保留，保存前备份配置；显式恢复默认和手动撤销继续保留。撤销可返回旧清单，旧清单可能再次隐藏新增模型。发现外部配置变动时不会擅自撤销。

若以后又缺新模型，应更新工具并按上述步骤保存，或在退出 Codex 后明确恢复默认，重新使用原生模型发现。不要删除文件、强行绕过检查或重签 Codex 来解决列表问题。官方依据见[模型清单文档](https://learn.chatgpt.com/docs/model-catalogs)和[Terra 发布说明](https://learn.chatgpt.com/docs/whats-new/october-26-30-2026)。

## 支持范围

已测试 macOS arm64、桌面内置 CLI `0.165.0-alpha.1.2`，位于 `/Applications/ChatGPT.app`。模型清单从本机官方 CLI 在隔离环境中取得，不随源码分发。当前 Astra 等可扩展模型的清单值为默认 272000、最大 872000；具体值以匹配版本的内置清单为准。

这里只修改本地官方配置声明，不解除服务器、账号或模型限制，也不保证现有聊天即时扩容。界面的“已启用”表示配置已保存并正确引用；聊天实际采用必须单独确认。此项目使用官方配置机制，是第三方工具，不是官方产品。

Codex 更新后，旧构建停止新增保存；工具保留安全手动撤销。应重新构建并验证当前版本，未知布局或不兼容模型清单会停止操作，不能假设未来版本兼容。

## 必要保护

工具仅编辑用户 `~/.codex/config.toml` 根级 `model_catalog_json`，使用完整当前清单，仅改变所选模型的上下文值；保留模型顺序、隐藏状态和其他字段。自有清单、私有备份与事务记录位于 `~/Library/Application Support/CodexContextSwitcher/`。保存前后检查配置身份与外部修改；发现冲突停止操作。保存中断保留备份及记录，不自动覆盖或回滚。

受限子进程禁止联网及读取聊天数据库、认证资料和钥匙串；不修改 Codex 应用，不代替用户结束原生进程。命令行仅允许真实配置的只读状态检查，写入测试命令只接受严格私有的一次性目录。公开源码不包含聊天、个人配置、备份、生成模型清单或其他产品模块。
